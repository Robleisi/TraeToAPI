# 快速上手（本地网关）

> 面向本机部署的最小操作手册。完整配置、端点能力与部署方式见 [README](../README.md)。

## 基本信息

| 项 | 值 |
|---|---|
| 网关地址 | `http://127.0.0.1:8899` |
| API Key | `.env` 中 `API_KEY`（默认 `your-master-key`） |
| OpenAI 接口 | `POST /v1/chat/completions` |
| Anthropic 接口 | `POST /v1/messages` |
| 模型列表 | `GET /v1/models` |
| 健康检查 | `GET /v1/status` |
| 用量总览 | `GET /api/overview`（需带 `Authorization: Bearer <key>`） |

## 启动与停止

```text
托盘（推荐）   双击 dist\TraeToAPI\TraeToAPI.exe → 常驻系统托盘，左键打开控制台，
               菜单可启动/停止/重启服务、改端口、设置开机自启动
命令行         双击 启动网关.bat / start.bat（日志落盘 gateway.log；端口读 .env 的 PORT，默认 8899）
停止           托盘「退出」或双击 停止网关.bat / stop.bat
```

首次使用：`copy .env.example .env`，按注释填写 `TRAE_AUTH_SOURCE` 与 token，再启动。
托盘 exe 的打包方法见 [README · 桌面版](../README.md#桌面版系统托盘)。
勿把 `.env` 或 `data/accounts.json` 提交到 Git。

## 模型

常用：`glm-5.3`、`glm-5.3-flash`、`kimi-k3`、`qwen3.8-max`、`deepseek-v4.1-flash`、`DeepSeek-V4-Pro-Official` 等，完整列表以 `GET /v1/models` 为准。

## 上游模式怎么选

| 场景 | 推荐 `UPSTREAM_MODE` | 理由 |
|---|---|---|
| DSH / Cursor BYOK 等本地工作区工具（模型只出 `tool_calls`，工具由调用方执行） | `ide` | TraeCode 本地聊天链路，无云端沙箱，首 token 约 2~7 秒 |
| 需要云端 Agent 沙箱代跑任务 | `remote` | Trae Remote 通道，每次新建会话有约 60 秒容器冷启动 |

`.env` 中 `UPSTREAM_MODE=ide` 即固定 IDE 通道；控制台「轮询与设置」也可运行时切换。

## 常见问题

1. **用量管理里标题显示 "Prompt"**：请求缺少顶层 `user_input` 字段导致服务端兜底；当前版本已在 `src/trae_client.py` 的 `build_llm_chat_body` 中补齐，取最后一条真实用户消息填入。
2. **`/v1/status` 500**：检查 `.env` 的 `TRAE_CLI_WORKDIR` 是否指向可写目录。
3. **Token 过期**：`.env` 的 `TRAE_TOKEN` 来自本机 Trae CN 的 `storage.json`，过期后重新提取并重启。
4. **积分消耗**：Trae agent 系统提示有约 24k~26k prompt tokens 的固定开销，单次请求约 5 积分上下。
